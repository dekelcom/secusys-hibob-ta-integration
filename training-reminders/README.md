# תזכורות אימונים והסעות — קסם צעירים (יונתן)

פותר שתי בעיות סביב הלו״ז החודשי שהמאמנת שולחת כתמונה בקבוצת הוואטסאפ:

1. **תזכורת ערב לפני כל אימון** (20:00) — מה מתוכנן למחר.
2. **ניהול הסעות** — מי לוקח ומי מחזיר, בלי לגלול היסטוריית הודעות בוואטסאפ.

## מה יש כאן

| קובץ | מה זה |
|------|-------|
| `schedule.json` | הלו״ז החודשי, מובנה בפורמט קריא למחשב. **מתעדכן כל חודש** כשמגיעה תמונה חדשה. |
| `generate_reminder.py` | סקריפט שמייצר את טקסט התזכורת לתאריך נתון (ברירת מחדל: מחר) מתוך `schedule.json`. |
| לוח ההסעות המקוון | עמוד משותף לניהול הסעות + כפתור העתקת תזכורת — ראו קישור למטה. |

## לוח ההסעות (עמוד משותף)

**https://claude.ai/code/artifact/c17eeaf8-d12a-4155-a255-c6ba65564988**

כל הורה שנכנס יכול להוסיף את עצמו כ"הלוך" או "חזור" לכל אימון, והשינוי נשמר לכולם באופן מיידי — בלי צורך בהתקנה או התחברות.
כדי שהורים בקבוצה יוכלו גם *לערוך* (לא רק לצפות), יש לשתף את הקישור דרך תפריט השיתוף של העמוד ולוודא שהרשאת העריכה פתוחה ("כל מי שיש לו את הקישור יכול לערוך").

## תזכורת ערב אוטומטית ב-20:00

מוגדרת משימה מתוזמנת (Routine) שבודקת כל ערב אם יש אימון למחר, ואם כן — שולחת התראה עם טקסט מוכן להעתקה + קישור ללוח ההסעות. ההתראה מגיעה אליך (לא נשלחת ישירות לקבוצה — אין API רשמי לשליחת הודעות לקבוצת וואטסאפ), ואז מעתיקים והודבקים לקבוצה בלחיצה אחת.

הרצה ידנית לבדיקה / לשימוש עצמאי (למשל אם תרצו לחבר את זה בעתיד לשירות שליחה משלכם):

```bash
python3 training-reminders/generate_reminder.py                 # תזכורת למחר
python3 training-reminders/generate_reminder.py 2026-09-14      # תאריך ספציפי
python3 training-reminders/generate_reminder.py --carpool-url "https://..." 
```

מדפיס טקסט (ריק אם אין אימון מחר) — קל לחבר לכל cron / שירות שליחה שתבחרו בעתיד.

## עדכון ללו״ז חדש (כל חודש)

כשהמאמנת שולחת תמונה חדשה של הלו״ז:

1. עדכנו את `schedule.json` עם האימונים החדשים (תאריך, יום, שעה, סוג אימון, מיקום, מאמן/ת).
2. עדכנו את אותם הנתונים בעמוד ההסעות המקוון (בקשו מקלוד לעדכן ולפרסם מחדש את הלוח, או ערכו את מקטע `SCHEDULE` בקובץ ה-HTML).
3. שינויי הסעות מהחודש הקודם נשארים בעמוד עד שיוחלפו — אפשר לנקות אותם באותה הזדמנות.

## למה אין שליחה אוטומטית ישירות לקבוצת הוואטסאפ

WhatsApp Business API הרשמי (Cloud API) לא תומך בשליחת הודעות לקבוצות כלל — רק שיחות אישיות. שליחה אוטומטית לקבוצה אפשרית רק דרך כלים לא-רשמיים (אוטומציה של WhatsApp Web/Baileys וכד'), שיש להם סיכון חסימה ודורשים מכשיר/שרת תמיד פעיל עם חשבון מחובר. לכן הפתרון כאן הוא "כמעט אוטומטי": הכל מוכן להעתקה, ורק לחיצת שיתוף אחת נשארת ידנית. אם בעתיד תרצו לחבר שירות שליחה (רשמי או צד-שלישי), `generate_reminder.py` כבר מפיק את הטקסט המוכן — צריך רק לחבר את פלט הסקריפט לשירות שתבחרו.
