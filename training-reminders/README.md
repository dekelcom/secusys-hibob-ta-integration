# תזכורות אימונים והסעות — קסם צעירים (יונתן)

פותר שתי בעיות סביב הלו״ז החודשי שהמאמנת שולחת כתמונה בקבוצת הוואטסאפ:

1. **תזכורת ערב לפני כל אימון** (20:00) — מה מתוכנן למחר.
2. **ניהול הסעות** — מי לוקח ומי מחזיר, בלי לגלול היסטוריית הודעות בוואטסאפ.

## מה יש כאן

| קובץ | מה זה |
|------|-------|
| `schedule.json` | הלו״ז החודשי, מובנה בפורמט קריא למחשב. **מתעדכן כל חודש** כשמגיעה תמונה חדשה. |
| `generate_reminder.py` | סקריפט שמייצר את טקסט התזכורת לתאריך נתון (ברירת מחדל: מחר) מתוך `schedule.json`. |
| `whatsapp-bot/` | בוט שמתחבר לוואטסאפ ושולח את התזכורת **אוטומטית וישירות לקבוצה**, בלי שום העתק-הדבק. |
| לוח ההסעות המקוון | עמוד משותף לניהול הסעות + כפתור העתקת תזכורת — ראו קישור למטה. |

## לוח ההסעות (עמוד משותף)

**https://claude.ai/code/artifact/c17eeaf8-d12a-4155-a255-c6ba65564988**

כל הורה שנכנס יכול להוסיף את עצמו כ"הלוך" או "חזור" לכל אימון, והשינוי נשמר לכולם באופן מיידי — בלי צורך בהתקנה או התחברות.
כדי שהורים בקבוצה יוכלו גם *לערוך* (לא רק לצפות), יש לשתף את הקישור דרך תפריט השיתוף של העמוד ולוודא שהרשאת העריכה פתוחה ("כל מי שיש לו את הקישור יכול לערוך").

## שליחה אוטומטית לקבוצה ב-20:00 (`whatsapp-bot/`)

זה הפתרון המלא: בוט שמתחבר לוואטסאפ שלכם כ**מכשיר מקושר** (בדיוק כמו WhatsApp Web/Desktop) ושולח את התזכורת ישירות לקבוצת ההורים — בלי שאתם נוגעים בזה בכלל, ובלבד שהמחשב שמריץ אותו דלוק וב-cron בשעה הנכונה.

**חשוב להבין לפני שמתקינים:**
- אין API רשמי של מטא לשליחה לקבוצות וואטסאפ (רק לשיחות אישיות) — הבוט משתמש בפרוטוקול הלא-רשמי (הספרייה [Baileys](https://github.com/WhiskeySockets/Baileys)), אותו מנגנון "מכשיר מקושר" שוואטסאפ עצמו חושף ל-WhatsApp Web. יש סיכון (נמוך אך לא אפס) לחסימה זמנית של המספר על אוטומציה. להודעה אחת ביום זה סיכון קטן, אבל אם רוצים ליישר קו לגמרי — אפשר לקשר מספר משני ("עוזר תזכורות") במקום המספר האישי, ולהוסיף אותו לקבוצה.
- הבוט **לא** רץ בתוך השיחה הזו עם קלוד — הסביבה כאן זמנית ומתאפסת. הוא צריך לרוץ על מחשב/שרת שלכם שנשאר דלוק (מחשב בבית, Raspberry Pi, או VPS קטן), ומתוזמן שם ב-cron.
- המספר המקושר (שלכם או המשני) חייב כבר להיות חבר בקבוצת ההורים, אחרת אין לו הרשאה לשלוח אליה.

**התקנה (חד-פעמית):**

```bash
cd training-reminders/whatsapp-bot
npm install
cp config.example.json config.json
npm run list-groups
```

`list-groups` יציג קוד QR בטרמינל — סרקו אותו מהטלפון: **הגדרות ← מכשירים מקושרים ← קישור מכשיר**. אחרי החיבור יודפסו כל הקבוצות שלכם עם ה-JID שלהן; העתיקו את זו של קבוצת ההורים לתוך `config.json` תחת `groupJid`. פרטי החיבור נשמרים בתיקיית `auth_info/` (לא ב-git — זה שקול לפתוח את הוואטסאפ שלכם, לא לשתף אף פעם).

בדיקה ידנית:
```bash
node send-reminder.js 2026-09-08   # תאריך ספציפי, לבדיקה
node send-reminder.js              # ברירת מחדל: מחר
```

תזמון יומי (crontab -e), כל ערב ב-20:00 שעון מקומי — הסקריפט עצמו בודק אם יש אימון למחר ולא שולח כלום אם אין, אז בטוח להריץ כל יום:
```
0 20 * * * cd /path/to/training-reminders/whatsapp-bot && /usr/bin/node send-reminder.js >> send.log 2>&1
```

**גיבוי:** בנוסף לבוט, מוגדרת התראה יומית (Routine בסביבת קלוד) שבודקת כל ערב אם יש אימון למחר ומתריעה אליכם עם טקסט מוכן — כרשת ביטחון למקרה שהמחשב עם הבוט כבוי או שהחיבור התנתק. אם הבוט עובד כסדרו, ההתראה הזו מיותרת בפועל; אפשר גם לבטל אותה בהמשך.

## עדכון ללו״ז חדש (כל חודש)

כשהמאמנת שולחת תמונה חדשה של הלו״ז:

1. עדכנו את `schedule.json` עם האימונים החדשים (תאריך, יום, שעה, סוג אימון, מיקום, מאמן/ת) — גם `generate_reminder.py` וגם `whatsapp-bot/` קוראים מאותו קובץ, אז עדכון אחד מספיק לשניהם.
2. עדכנו את אותם הנתונים בעמוד ההסעות המקוון (בקשו מקלוד לעדכן ולפרסם מחדש את הלוח, או ערכו את מקטע `SCHEDULE` בקובץ ה-HTML).
3. שינויי הסעות מהחודש הקודם נשארים בעמוד עד שיוחלפו — אפשר לנקות אותם באותה הזדמנות.
